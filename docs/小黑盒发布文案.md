## 正文

大家好，我是大肥鱼🐟。

用 Steam Deck 玩游戏的时候，想听歌就得切出去开手机/电脑，多少有点打断。于是我折腾了一个 **Decky Loader 插件**——在 **游戏模式（Game Mode）** 里就能直接搜歌、听歌、看歌词，还能在 **QAM（··· 快捷菜单）** 里一键控制。现在开源出来了，分享给同样需要的盒友。

### 🎵 它能干啥

- **QAM 控制面板**：封面、歌名/歌手、滚动歌词、进度条、上一首/播放/下一首、音量、播放模式（列表循环 / 顺序 / 单曲 / 随机）。
- **全屏音乐库**：发现（推荐歌单、排行榜、新歌）、搜索（单曲/歌单/专辑/歌手，支持**拼音实时联想**，比如 `zhoujielun` 就能出「周杰伦」）、我的（歌单、音质选择）。
- **全屏沉浸播放页（Folia 风）**：封面模糊取色背景 + 莫奈取色动态流光；歌词居中、当前行放大高亮带呼吸辉光、上下行渐隐、平滑滚动，**逐字歌词（yrc）卡拉 OK 式点亮**，还带翻译行；红心收藏。
- **登录**：扫码 / 账号密码 / **Cookie 导入**（被 8821 风控时用 Cookie 最稳）。
- **低占用**：纯 Python 后端 + 单例 HTML5 音频，关掉 QAM 音乐也不中断。
- **手柄友好**：全自定义控件接入焦点树，D-pad / A 键就能操作。

### 📦 安装

1. 先装好 **Decky Loader**（GitHub 搜 decky-loader）。
2. 到项目 **Releases** 页面下载 `decky-netease-music-decky.zip`。
3. Decky 设置 → 开发者 → **Install Plugin from ZIP**，选这个 zip。
4. 重启 Decky / 重新加载插件，QAM 里就能看到「网易云音乐」。

> 安装后无需 Node，也不需要 node_modules，运行时零额外依赖。

### 🔑 登录小贴士

网易云扫码有时会遇到 **8821 风控**（"请切换其他登录方式"）。最稳的办法是 **Cookie 登录**：
- 电脑浏览器登录 music.163.com → F12 → Application → Cookies → 复制 `MUSIC_U`（和 `__csrf`），粘贴到插件里「Cookie 登录」即可。
- 或者把 `cookie.txt` 放到 Deck 上，用「选择文件导入」。

- 本项目**只调用网易云公开接口**，不做破解、不提供下载，能不能播放取决于账号与版权。
