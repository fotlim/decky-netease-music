# 更新日志 / Changelog

## v1.5.2

## v1.5.1
- **移除内置 Node/增强 API 服务与「自动获取 Cookie」相关功能**，插件恢复轻量版（zip 约 50KB，无外部依赖/无 Node 进程）。登录保留：扫码 / 账号密码 / Cookie 导入（手动粘贴、选择文件、刷新状态）。
- 播放页/面板样式类问题留待按方案修复（见下）。

## v1.5.0
- **把 NeteaseCloudMusicApiEnhanced 服务内置进插件**：Node 22 (linux-x64) 运行时 + 精简后的依赖（去 .pnpm/文档/测试/类型声明，34.6MB），插件启动时在 Deck 本地拉起（`127.0.0.1:39000`），xeapi/匿名 token/设备指纹全由它处理。
- 登录页新增 **「⬇ 自动获取 Cookie」**：直接扫码 → 内置服务完成风控 → 返回 cookie 自动写入并登录，**绕开 8821**，全程无需电脑/外部服务。地址留空=用内置服务，也可填外部服务器。
- 打包约 56MB（含 Node 运行时），安装后插件目录约 147MB。

## v1.4.1
- 新增 **「网页自动获取 Cookie」**：`获取Cookie.html` + `打开网页获取Cookie.cmd`，连接本地 API 服务扫码，成功后网页直接显示并可复制 `MUSIC_U`/整段 Cookie（免 F12 手动查找），支持一键下载 `cookie.txt`。
- 提供 `启动网易云API服务.cmd`（`npx @neteasecloudmusicapienhanced/api`，默认 3000 端口）。

## v1.4.0
- 新增 **「服务器登录」**：插件对接外部 `NeteaseCloudMusicApiEnhanced` 服务（`/login/qr/key|create|check`），由服务端完成 xeapi/匿名 token/设备指纹，**绕开 8821**；登录页可填服务器地址（默认 `http://192.168.137.1:3000`），服务端返回二维码 dataURL 直接显示、803 返回 cookie 自动登录。
- 后端新增 `server_qr_start/server_qr_check`，本机真机联调通过（key + qrimg(dataURL) + 801）。
- 提供电脑端「启动网易云API服务」脚本（`npx @neteasecloudmusicapienhanced/api`）。
